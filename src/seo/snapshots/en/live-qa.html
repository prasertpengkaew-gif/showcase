A simple seminar idea

How it works

People scan a QR code, type a question and vote on others. The host puts one question on the main screen, and the word cloud updates by itself.

Good to know

Quiet rooms speak up

People who would not raise a hand will type a question, and the best-voted ones rise to the top.

Host stays in control

Only questions the host selects reach the screen, so nothing unexpected is shown to the room.

Concept only

A real event needs a server so phones can share one list, plus a way to remove spam.
