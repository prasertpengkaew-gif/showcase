Connect your plant

The twin reads machine data from a WebSocket feed. A small gateway translates your PLCs, OPC UA server or MQTT broker into this format; set its address in VITE_TWIN_WS_URL and the page switches from simulated to live data.

Message format

{ "machines": [ { "id": "press-1", "status": "warning", "temperature": 86.4, "throughput": 27, "vibration": 3.1 } ] }

What a digital twin is used for

  • Line monitoring

    One shared view of every machine for supervisors, maintenance and management.

  • Faster response

    Faults and overheating are visible the moment they happen, on the machine where they happen.

  • Planning & training

    Try layout changes and train new staff on a virtual line before touching the real one.
