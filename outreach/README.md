# outreach: หาบริษัทรับจัดงาน แล้วร่างเมลนำเสนอ

เครื่องมือในเครื่องของคุณ (ไม่ใช่ส่วนของเว็บ ไม่ถูก deploy) ทำ 4 ขั้น: **ค้นหาเว็บไซต์ → สแกนเก็บข้อมูลติดต่อ → ร่างเมลภาษาไทย → คุณตรวจแล้วส่งเอง** ไม่มีการส่งเมลอัตโนมัติ

ใช้ Node 20 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม รันจากโฟลเดอร์ `showcase`

```bash
node outreach/discover.mjs     # 1. ค้นหาเว็บไซต์บริษัทตามคำค้นใน queries.txt  -> data/sites.txt
node outreach/scan.mjs         # 2. อ่านเว็บไซต์แต่ละแห่ง เก็บชื่อ อีเมล เบอร์ ประเภทงาน -> data/companies.json
node outreach/draft.mjs        # 3. ร่างเมล -> data/review.html (เปิดในเบราว์เซอร์)
node outreach/mark.mjs sent acme.co.th    # 4. ส่งแล้ว บันทึกไว้ จะได้ไม่ร่างซ้ำ
node outreach/test.mjs         # ทดสอบตรรกะ (ไม่ใช้อินเทอร์เน็ต)
```

## ก่อนเริ่ม

1. ใส่ชื่อผู้ส่งใน `outreach/config.json` (`sender.name`, `role`, `phone`) และเลือก `polite` เป็น `ครับ` หรือ `ค่ะ` ถ้าไม่ใส่ชื่อ ร่างเมลจะมีคำเตือนและช่อง `[ชื่อผู้ส่ง]`
2. เพิ่มคำค้นใน `queries.txt` ได้ตามต้องการ (จังหวัด ประเภทงาน ภาษาอังกฤษ) หรือใส่เว็บไซต์เองใน `data/sites.txt` บรรทัดละเว็บ

## แต่ละขั้นทำอะไร

**discover.mjs** ค้นหาแล้วเก็บเฉพาะโดเมนที่น่าจะเป็นบริษัท ตัดโซเชียล เว็บหางาน ไดเรกทอรี ข่าว และเว็บราชการออก (เพิ่มเองได้ที่ `data/blocklist.txt`)
- ถ้ามี `BRAVE_API_KEY` ใช้ Brave Search API (ทางการ มีโควตาฟรี) ถ้าไม่มี ใช้หน้า HTML ของ DuckDuckGo ซึ่งเงื่อนไขของเขาไม่สนับสนุนการค้นแบบอัตโนมัติ เครื่องมือจึงหน่วงเวลาหลายวินาทีและหยุดทันทีเมื่อถูกขอให้ยืนยันว่าเป็นคน ถ้าจะค้นปริมาณมาก ควรใช้ Brave API

**scan.mjs** อ่านหน้าแรกและอีก 3–4 หน้า (ติดต่อ เกี่ยวกับเรา บริการ ผลงาน) เก็บเฉพาะข้อมูลที่เว็บเปิดเผยไว้
- เคารพ `robots.txt` (ถ้าเว็บห้ามหรือเปิด robots.txt ไม่ได้ จะข้าม) หน่วง 2.5 วินาทีต่อคำขอต่อเว็บ แจ้งตัวตนใน User-Agent พร้อมอีเมลติดต่อ
- เก็บ: ชื่อ คำอธิบาย ภาษาของเว็บ อีเมล เบอร์โทร LINE โซเชียล และ **ประเภทงานที่เขารับ** (งานแสดงสินค้า เปิดตัวสินค้า activation สัมมนา คอนเสิร์ต งานแต่ง งานองค์กร) กับ **คะแนนความเกี่ยวข้อง 0–100** ว่าเป็นบริษัทอีเวนต์จริงแค่ไหน
- อีเมลแบ่งเป็น `role` (info@, contact@ ฯลฯ ที่เป็นกล่องกลางของบริษัท) `freemail` (gmail ฯลฯ) และ `named` (เหมือนชื่อบุคคล)

**draft.mjs** เลือกอีเมลที่เหมาะที่สุด 1 ที่อยู่ต่อบริษัท เลือกแม่แบบและข้อความตามประเภทงานของเขา และสร้างหน้า `data/review.html`
- แก้ข้อความในช่องได้เลย แล้วกด "คัดลอกเมล" "เปิดใน Gmail" หรือ "เปิดในแอปอีเมล" ส่งเองจากบัญชีของคุณ
- ตัวเลือก: `--min-score=40` เอาเฉพาะบริษัทที่ชัดเจน, `--limit=20`, `--include-named` (เขียนถึงอีเมลชื่อบุคคลด้วย ปิดไว้เป็นค่าเริ่มต้น)
- ข้อเสนอในเมลมีเฉพาะสิ่งที่มีเดโมจริงบนเว็บของเรา (ตู้ถ่ายรูป AR ล่าสมบัติ AR เกมขยับตัว AR บนโปสเตอร์) ไม่อ้างลูกค้าหรือผลงานที่ไม่มีจริง

**mark.mjs** บันทึกผล: `sent` (ส่งแล้ว) `replied` (ตอบกลับ) `optout` (ขอไม่รับ ใส่โดเมนหรืออีเมลเต็ม) `skip` (ไม่สนใจ) บริษัทเหล่านี้จะไม่ถูกร่างเมลอีก

## เรื่องที่ต้องระวัง (กฎหมายและชื่อเสียง)

- **ข้อมูลบริษัทและอีเมลอยู่ใน `outreach/data/` ซึ่งถูก gitignore** repo showcase เป็นสาธารณะ ห้ามเอาโฟลเดอร์นี้ขึ้น GitHub
- อีเมลที่เป็นชื่อบุคคลถือเป็นข้อมูลส่วนบุคคลตาม PDPA เครื่องมือจึงไม่ใช้เป็นค่าเริ่มต้น ใช้เฉพาะกล่องกลางของบริษัท ควรส่งเมลน้อยฉบับ เฉพาะบริษัทที่เกี่ยวข้องจริง และเขียนต่างกันตามบริษัท (ระบบทำให้บางส่วน คุณควรอ่านและแก้ก่อนส่งเสมอ)
- ทุกฉบับมีบรรทัดบอกว่าได้อีเมลมาจากไหน และวิธีขอไม่รับเมลอีก เมื่อมีคนตอบ "ไม่รับ" ให้รัน `mark.mjs optout` ทันที
- อย่าส่งจำนวนมากพร้อมกันจากโดเมน `thenerdstudio.space` ที่ใช้กับงานจริง เสี่ยงโดนมองเป็นสแปมและกระทบการส่งเมลของโดเมน ควรทยอยส่งวันละไม่กี่สิบฉบับ
- ผลสแกนอาจผิดได้ (เว็บเก่า อีเมลเลิกใช้ เว็บโหลดข้อมูลด้วย JavaScript ซึ่งเครื่องมืออ่านไม่เห็น) ตรวจหน้า review ก่อนส่งทุกครั้ง

## ไฟล์ในโฟลเดอร์ `data/` (ไม่ขึ้น git)

`sites.txt` รายชื่อเว็บ · `companies.json` ผลสแกน (แก้ `status` และ `notes` เองได้ ระบบไม่เขียนทับ) · `review.html` หน้าตรวจร่าง · `drafts/` และ `drafts.csv` · `sent.txt` · `suppress.txt` · `blocklist.txt`

## ให้ AI ช่วยอ่านเว็บไซต์ (ไม่บังคับ)

เครื่อง AI ในวง LAN (`llm.baseUrl` ใน `config.json`, API แบบ OpenAI) ช่วยอ่านข้อความเว็บของแต่ละบริษัท:

```bash
node outreach/scan.mjs --force    # สแกนใหม่ 1 ครั้ง เพื่อเก็บข้อความหน้าเว็บไว้ใน data/pages/
node outreach/enrich.mjs          # ให้ AI อ่านทีละบริษัท (~3 วินาที/บริษัท)
node outreach/draft.mjs
```

AI ตอบว่าเป็นบริษัทจัดอีเวนต์จริงไหม (`no` จะถูกข้ามตอนร่างเมล) และจัดงานประเภทไหน ซึ่งใช้เลือกข้อความในเมล
คำตอบถูกตรวจก่อนใช้ ประเภทที่ไม่รู้จักและคำอ้างอิงที่ไม่มีอยู่ในเว็บจริงจะถูกทิ้ง ถ้าเครื่อง AI ปิดอยู่ ระบบเดิมทำงานต่อได้ตามปกติ
