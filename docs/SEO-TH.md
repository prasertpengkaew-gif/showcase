# SEO ภาษาไทย — ให้ลูกค้าหาเราเจอบน Google

เอกสารนี้อธิบายว่าเว็บทำอะไรไว้แล้ว และสิ่งที่ต้องทำเองหลังเปิดเว็บ **ไม่มีใครรับประกันอันดับบน Google ได้** อันดับขึ้นกับคู่แข่ง อายุเว็บ และลิงก์จากเว็บอื่น การเริ่มติดอันดับมักใช้เวลาหลายวันถึงหลายสัปดาห์

## เว็บทำอะไรไว้แล้ว

- **ภาษาไทยเป็นค่าเริ่มต้นสำหรับ Google** — Googlebot ประกาศตัวเป็นภาษาอังกฤษ เว็บจึงตรวจจากชื่อบอตแล้วแสดงภาษาไทยให้ ผู้ใช้จริงยังได้ภาษาตามเบราว์เซอร์เหมือนเดิม
- **HTML จริงทุกหน้า** (30 หน้า) — ตอน `npm run build` สคริปต์ `scripts/prerender.mjs` เขียนไฟล์ HTML ของแต่ละหน้าพร้อมชื่อหน้า (title) คำอธิบาย (description) ลิงก์ canonical และเนื้อหาข้อความ Google อ่านได้ทันทีโดยไม่ต้องรอรัน JavaScript
- **ข้อความค้นหาภาษาไทยทุกหน้า** อยู่ที่ `src/seo/pages.ts` (ไทยและอังกฤษ) เช่น "AR Photo Booth ตู้ถ่ายรูป AR สำหรับงานอีเวนต์ เช่าได้", "Digital Twin โรงงาน 3D", "แผนที่ 3D แบบโต้ตอบ"
- **sitemap.xml และ robots.txt** สร้างอัตโนมัติ (ไม่รวมหน้าตู้ถ่ายรูป `/booth/` และหน้ารูปของแขก `/p/` ซึ่งเป็นหน้าส่วนตัว)
- **ข้อมูลโครงสร้าง (JSON-LD)** — ธุรกิจ (ProfessionalService, พื้นที่ให้บริการ: ประเทศไทย), เว็บไซต์, เส้นทางนำทาง (breadcrumb), รายการบริการ, ผลงาน
- **การ์ดแชร์** (Open Graph) สำหรับ LINE, Facebook — รูป `public/og-image.png` (สร้างใหม่ด้วย `node scripts/make-og-image.mjs`)
- หน้าที่ไม่มีอยู่จริงบอก Google ว่าไม่ต้องเก็บ (noindex)

## ต้องทำเองหลังเปิดเว็บ (สำคัญที่สุด)

1. **ตั้งค่าที่อยู่เว็บจริง** — ใน Vercel → Settings → Environment Variables เพิ่ม `VITE_SITE_URL` = `https://โดเมนของคุณ` แล้ว Redeploy ถ้าไม่ตั้ง จะใช้ที่อยู่ `*.vercel.app` ของโปรเจกต์
2. **ซื้อโดเมนของตัวเอง** (เช่น `thenerdstudio.co.th` หรือ `.com`) แล้วผูกกับ Vercel — โดเมนของตัวเองน่าเชื่อถือกว่า `*.vercel.app` มาก และเปลี่ยนที่อยู่ทีหลังจะเสียอันดับ จึงควรทำก่อนเริ่มโปรโมต
3. **Google Search Console** (search.google.com/search-console)
   - เพิ่มเว็บของคุณ ยืนยันความเป็นเจ้าของ (ง่ายสุดคือผ่าน DNS ของโดเมน)
   - เมนู Sitemaps → ใส่ `sitemap.xml` → ส่ง
   - เมนู URL Inspection → ใส่หน้าแรก → Request indexing
   - กลับมาดูเมนู Performance ว่าคนค้นด้วยคำอะไรแล้วเข้ามา เพื่อปรับข้อความ
4. **Google Business Profile** — ถ้ามีที่อยู่หรือรับลูกค้าในพื้นที่ ช่วยให้ขึ้นในแผนที่และการค้นหาท้องถิ่น
5. **ใส่ข้อมูลติดต่อจริง** ใน `.env` (เบอร์โทร ที่อยู่ LINE Facebook) — เว็บจะใส่ลง JSON-LD ให้เอง Google ใช้ข้อมูลที่ตรงกันทุกที่เป็นสัญญาณความน่าเชื่อถือ
6. **สร้างลิงก์ย้อนกลับ** — ให้ Facebook เพจ, LINE OA, โปรไฟล์บริษัท, บทความ หรือลูกค้าที่ทำงานด้วยลิงก์มาที่เว็บ นี่คือสิ่งที่ส่งผลต่ออันดับมากที่สุดและเราทำแทนในโค้ดไม่ได้
7. **เขียนเนื้อหาที่คนค้นหา** — เช่นบทความ "ตู้ถ่ายรูป AR สำหรับงานแต่งราคาเท่าไร", "AR คืออะไร ใช้กับธุรกิจอย่างไร" ตอนนี้เว็บมีหน้าบริการและเดโมเป็นหลัก ยังไม่มีบทความ

## วิธีเปลี่ยนคำที่ใช้ค้นหา

แก้ที่ `src/seo/pages.ts` (title ไม่เกินราว 60 ตัวอักษร, description ไม่เกินราว 160) แล้ว `npm run build` — ชื่อหน้าบนแท็บและ HTML ล่วงหน้าจะเปลี่ยนตาม ตรวจด้วย `npm run test:seo`

## ข้อจำกัดที่รู้อยู่

- เวอร์ชันภาษาอังกฤษสลับได้ด้วยปุ่มภาษาเท่านั้น (ไม่มี URL แยก) Google จึงเก็บเฉพาะเวอร์ชันไทย หากต้องการให้ค้นหาภาษาอังกฤษเจอด้วย ต้องแยก URL เป็น `/en/...` ซึ่งเป็นงานเพิ่ม
- เนื้อหาในหน้าส่วนใหญ่โหลดด้วย JavaScript และ 3D หนัก คะแนนความเร็ว (Core Web Vitals) ยังไม่ได้วัดบนเครื่องจริง ควรทดสอบด้วย PageSpeed Insights หลังเปิดเว็บ และ Google ใช้ความเร็วเป็นปัจจัยหนึ่ง
- รูปแชร์ (og-image) เป็นภาษาอังกฤษเพราะเครื่องที่สร้างไม่มีฟอนต์ไทย
- ยังไม่ได้ทดสอบกับ Google จริง (ในนี้ทดสอบได้เฉพาะว่า HTML ที่ได้ถูกต้องและบอตเห็นภาษาไทย) ใช้เครื่องมือ **Rich Results Test** และ **URL Inspection** หลังเปิดเว็บเพื่อยืนยัน
